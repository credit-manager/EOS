## 1. نظرة عامة على المعالج

### 1.1 الغرض والأهداف

المعالج (Onboarding Wizard) هو الميزة المحورية في EOS التي تتيح لأي نشاط تجاري إعداد نظام ERP الخاص به تلقائياً بناءً على القطاع الذي ينتمي إليه. يحل المعالج مشكلة التعقيد الهيكلي في أنظمة ERP التقليدية، حيث يُحوّل عملية الإعداد من أسابيع إلى دقائق.

**الأهداف الرئيسية:**

| الهدف | الوصف | مؤشر القياس |
|-------|-------|-------------|
| **تقليل وقت الإعداد** | تحويل عملية الإعداد اليدوية إلى معالج ذكي تلقائي | Completion time < 10 دقائق |
| **زيادة معدل التحويل** | تقليل نقاط الانسحاب خلال عملية التسجيل | Completion rate > 70% |
| **تخصيص القطاع تلقائياً** | تفعيل الوحدات والإعدادات حسب_sector دون تدخل يدوي | Manual config < 5% |
| **تجربة مستخدم متكاملة** | واجهة عربية سلسة مع دعم كامل للغة الإنجليزية | CSAT > 4.5/5 |
| **زيادة الدخل** | عرض الخطط والإضافات بشكل ذكي أثناء المعالج | ARPU increase > 20% |

### 1.2 مبادئ تجربة المستخدم

المعالج مبني على ثلاث مبادئ أساسية:

**البساطة (Simple)**
- كل شاشة تُعالج فكرة واحدة فقط
- حد أقصى 5-6 حقول لكل شاشة
- تلميحات سريعة (Tooltips) لكل حقل
- رسائل خطأ واضحة بالم潟 العربي

**السرعة (Fast)**
- شاشة التسجيل: < 60 ثانية
- معلومات الشركة: < 2 دقيقة
- استبيان الاحتياجات: < 2 دقيقة
- اختيار الخطة: < 1 دقيقة
- الإعداد التلقائي: < 2 دقيقة (خفي)
- القدوم: < 1 دقيقة

**الذكاء (Smart)**
- اقتراحات ذكية بناءً على الإجابات السابقة
- تلخيص تلقائي للوحدات المختارة
- مقارنة مع أنشطة مشابهة في نفس القطاع
- تذكر التقدم في المعالج (Resume capability)

### 1.3 الأداء المطلوب

| المقياس | الهدف |
|---------|-------|
| متوسط وقت الإكمال | 5-10 دقائق |
| معدل إكمال المعالج | > 70% |
| وقت تحميل كل شاشة | < 2 ثانية |
| وقت الإعداد التلقائي | < 30 ثانية |
| معدل رضا المستخدمين | > 4.5/5 |
| معدل تحويل Free Trial | > 25% |

**حقول النموذج:**

| الحقل | النوع | مطلوب | التحقق | الوصف |
|-------|-------|-------|--------|-------|
| `full_name` | text | نعم | 3-100 حرف، عربي أو إنجليزي | الاسم الكامل للمستخدم |
| `email` | email | نعم | تنسيق بريد صحيح، فريد | البريد الإلكتروني |
| `phone` | tel | لا | تنسيق دولي صحيح | رقم الهاتف (مع رمز الدولة) |
| `password` | password | نعم | 8+ أحرف، كبيرة+صغيرة+رقم | كلمة المرور |
| `confirm_password` | password | نعم | يطابق password | تأكيد كلمة المرور |

**قواعد التحقق:**

```typescript
interface RegistrationValidation {
  full_name: {
    minLength: 3;
    maxLength: 100;
    pattern: /^[a-zA-Z\u0600-\u06FF\s]+$/; // Arabic + English + spaces
  };
  email: {
    pattern: /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    asyncCheck: 'available'; // Check uniqueness
  };
  phone: {
    pattern: /^\+[1-9]\d{6,14}$/; // E.164 format
    optional: true;
  };
  password: {
    minLength: 8;
    requireUppercase: true;
    requireLowercase: true;
    requireDigit: true;
    strengthIndicator: true; // weak/fair/strong
  };
}
```

| **Industry Distribution** | توزيع المستخدمين حسب القطاع | diversified | count by industry |
