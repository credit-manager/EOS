# P6.4.8 — Error Message Contract

**Status:** COMPLETE
**Date:** 2026-08-24

---

## 1. Changes Made

### Endpoints Updated to Structured Errors

| Endpoint | Before | After |
|----------|--------|-------|
| POST validation | `detail=str(e)` | `{error: {code: "VALIDATION_ERROR", details: [...]}}` |
| POST NOT NULL | `detail="; ".join(errors)` | `{error: {code: "NOT_NULL_VIOLATION", details: [...]}}` |
| POST duplicate | `detail="; ".join(errors)` | `{error: {code: "DUPLICATE_RECORD", details: [...]}}` |
| POST/PUT/PUT DB error | `detail=str(e)` | `{error: {code: "DATABASE_ERROR"}}` |

## 2. Error Response Format

```json
{
  "status": "error",
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "أخطاء في التحقق من البيانات",
    "message_en": "Validation errors",
    "details": [
      {
        "message": "الحقل 'code' مطلوب",
        "message_en": "Field 'code' is required"
      }
    ]
  },
  "meta": {
    "request_id": "uuid",
    "timestamp": "2026-08-24T12:00:00Z"
  }
}
```

| Before | After |
