## 2. Detailed Verification

### 2.1 Response Wrapper

**Contract:**
```json
{
  "status": "success",
  "data": { ... },
  "meta": { "request_id", "timestamp", "entity_code", "tenant_capability", "effective_tenant" }
}
```

**Current Code (dynamic_crud.py):**

| Endpoint | Current Response | Contract Match |
|----------|------------------|----------------|
| GET schema | `{status, data, table, tenant_capability, real_columns}` | ⚠️ Missing `meta` |
| GET records | `{status, data, count, tenant_applied, effective_tenant}` | ⚠️ Missing `meta` |
| POST records | `{status, id, message, tenant_capability, effective_tenant}` | ❌ Missing `data` wrapper |
| PUT records | `{status, message}` | ❌ Missing `data`, `meta` |
| DELETE records | `{status, message}` | ❌ Missing `data`, `meta` |

**Gap:** Response format inconsistent. No standard `meta` object.

---

### 2.2 Pagination

**Contract:**
```json
{
  "pagination": {
    "total": 150,
    "limit": 100,
    "offset": 0,
    "has_more": true
  }
}
```

**Current Code:**
```python
# Only limit parameter exists
@router.get("/entities/{entity_code}/records")
async def list_records(
    entity_code: str,
    limit: int = 100,
    ...
):
```

**Gap:** No `offset`, no `total`, no `has_more`.

### 2.3 PUT Response

### 2.5 Error Format

**Contract:**
```json
{
  "status": "error",
  "error": {
    "code": "ENTITY_NOT_FOUND",
    "message": "الكيان 'xyz' غير موجود",
    "message_en": "Entity 'xyz' not found"
  },
  "meta": { "request_id", "timestamp" }
}
```

**Current Code:**
```python
raise HTTPException(
    status_code=404,
    detail=f"الكيان '{entity_code}' غير موجود"
)
# Returns: {"detail": "الكيان 'xyz' غير موجود"}
```

**Gap:** No error codes. No `message_en`. No `meta`. Different body format.

---

### 2.6 Request ID

**Contract:**
```
X-Request-ID: <uuid> (client sends or server generates)
Response meta.request_id: <uuid>
```

**Current Code:** No request ID support.

---

### 2.7 Field Validation

**Contract:**
- Validate field_type (string, integer, decimal, boolean, date, datetime, json, enum)
- Validate constraints (maxLength, min, max)
- Return `{field, code, message, message_en}` for each error

**Current Code:**
```python
# Only validates:
# 1. Required fields (via MetadataEngine)
# 2. Enum values (via MetadataEngine)
# 3. NOT NULL columns (via DynamicVerificationEngine)
# 4. Unique constraints (via DynamicVerificationEngine)
```

**Gap:** No type validation. No constraint validation.
