# P6.4.6 — Pagination / Resource Limits

**Status:** COMPLETE
**Date:** 2026-08-24

---

## 1. Changes Made

### GET `/entities/{code}/records`

**New Query Parameters:**
| Param | Type | Default | Range | Description |
|-------|------|---------|-------|-------------|
| `limit` | integer | 100 | 1-1000 | Max records per page |
| `offset` | integer | 0 | 0+ | Records to skip |

**New Response Field:**
```json
{
  "pagination": {
    "total": 150,
    "limit": 100,
    "offset": 0,
    "has_more": true
  }
}
```

## 2. Resource Limits

| Limit | Value | Purpose |
|-------|-------|---------|
| `limit` min | 1 | Prevent empty queries |
| `limit` max | 1000 | Prevent memory exhaustion |
| `offset` min | 0 | No negative offset |

## 3. Implementation

```python
# Enforce limits
limit = min(max(limit, 1), 1000)
offset = max(offset, 0)

# COUNT query for total
total = db.execute(count_query).scalar()

# Pagination calculation
has_more = (offset + limit) < total
```
