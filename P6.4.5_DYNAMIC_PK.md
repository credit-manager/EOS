# P6.4.5 — Dynamic PK Handling

**Status:** COMPLETE
**Date:** 2026-08-24

---

## 1. Problem

```python
# BEFORE (hardcoded UUID)
clean_data = {"id": str(uuid.uuid4())}
RETURNING id
```

Tables with INTEGER or VARCHAR PKs would fail.

## 2. Solution

### core/dynamic_verification.py

New methods:
- `_inspect_table()` — detects PK column and type from PostgreSQL schema
- `generate_pk_value()` — generates appropriate PK based on type
- `get_pk_column()` — returns PK column name

### PK Type Support

| PostgreSQL Type | Generated Value |
|-----------------|-----------------|
| UUID | `str(uuid.uuid4())` |
| INTEGER | `MAX(id) + 1` |
| VARCHAR/STRING | `str(uuid.uuid4())` |

## 3. Changes Made

| File | Change |
|------|--------|
| `core/dynamic_verification.py` | Added PK detection and generation |
| `routers/dynamic_crud.py` | Use `verification.generate_pk_value()` |
