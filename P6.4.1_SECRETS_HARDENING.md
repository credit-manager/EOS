## 4. Required Manual Actions

```
1. Change PostgreSQL password
   ALTER USER eos WITH PASSWORD 'new_secure_password';

2. Update .env files
   DATABASE_URL=postgresql://eos:new_secure_password@...

3. Generate production SECRET_KEY
   python -c "import secrets; print(secrets.token_urlsafe(64))"

4. Update eos-system/backend/.env
   SECRET_KEY=<generated_key>

5. Verify connection
   python -c "from database import engine; engine.connect()"
```
