# P6.4.7 — Rate Limiting

**Status:** COMPLETE
**Date:** 2026-08-24

---

## 1. New File: core/rate_limit.py

### RateLimiter Class

- Sliding window algorithm
- In-memory storage (per-worker)
- Configurable limits per endpoint

### Pre-configured Limiters

| Limiter | Max Requests | Window | Use Case |
|---------|--------------|--------|----------|
| `default_limiter` | 100 | 60s | General API |
| `read_limiter` | 200 | 60s | GET endpoints |
| `write_limiter` | 50 | 60s | POST/PUT/DELETE |
| `auth_limiter` | 10 | 60s | Auth endpoints |

## 2. Endpoint Assignments

| Endpoint | Rate Limit |
|----------|------------|
| GET /schema | 200/min |
| GET /records | 200/min |
| POST /records | 50/min |
| PUT /records/{id} | 50/min |
| DELETE /records/{id} | 50/min |

## 3. Response Headers

When rate limit exceeded:
```
HTTP/1.1 429 Too Many Requests
Retry-After: 60
X-RateLimit-Limit: 50
X-RateLimit-Remaining: 0
```
