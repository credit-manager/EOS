# نظام ERP متكامل للشركات الصغيرة والمتوسطة

## نظرة عامة
نظام ERP (تخطيط موارد المؤسسات) قابل للتخصيص بالكامل ليناسب أي نشاط تجاري. تم تصميم النظام ليعمل على منصات متعددة (ويب وسطح مكتب) ويدعم الشركات الصغيرة والمتوسطة الحجم.

## التقنيات المستخدمة

### لغة البرمجة (Backend)
- **Python 3.10+**: اللغة الأساسية للنظام
- **FastAPI**: إطار عمل عالي الأداء لبناء واجهات API
- **SQLAlchemy**: ORM للتعامل مع قواعد البيانات
- **Pydantic**: للتحقق من صحة البيانات

### قاعدة البيانات
- **PostgreSQL**: قاعدة البيانات الأساسية (موصى بها للإنتاج)
- **SQLite**: للتطوير والاختبار
- **Redis**: للتخزين المؤقت وإدارة الجلسات

### واجهة المستخدم (Frontend)
- **React 18+**: مكتبة JavaScript لبناء واجهات المستخدم
- **TypeScript**: للكتابة الآمنة نوعياً
- **Tailwind CSS**: لتصميم الواجهات
- **Redux Toolkit**: لإدارة حالة التطبيق
- **React Query**: لإدارة بيانات الخادم

### تطبيقات سطح المكتب
- **Electron**: لتغليف تطبيق الويب كتطبيق سطح مكتب
- **Tauri** (بديل خفيف): خيار بديل لـ Electron

### ميزات إضافية
- **Docker**: للحاويات والنشر
- **Nginx**: كخادم وكيل عكسي
- **Celery**: للمهام غير المتزامنة
- **WebSocket**: للاتصالات في الوقت الفعلي

## متطلبات النظام

### الحد الأدنى
- معالج: 2 نواة
- ذاكرة RAM: 4 جيجابايت
- مساحة تخزين: 10 جيجابايت
- نظام تشغيل: Windows 10+, macOS 10.15+, Linux (Ubuntu 20.04+)

### الموصى به
- معالج: 4 نوى أو أكثر
- ذاكرة RAM: 8 جيجابايت أو أكثر
- مساحة تخزين: 50 جيجابايت SSD
- اتصال إنترنت مستقر (للنسخ السحابية)

## التثبيت السريع

### باستخدام Docker (الأسهل)
```bash
# استنساخ المستودع
git clone <repository-url>
cd erp-system

# بدء جميع الخدمات
docker-compose up -d

# الوصول إلى التطبيق
# الويب: http://localhost:3000
# API: http://localhost:8000
```

### التثبيت اليدوي

#### الخلفية (Backend)
```bash
cd backend
python -m venv venv
source venv/bin/activate  # على Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

#### الواجهة الأمامية (Frontend)
```bash
cd frontend
npm install
npm run dev
```

#### تطبيق سطح المكتب
```bash
cd desktop
npm install
npm run electron:dev
```
